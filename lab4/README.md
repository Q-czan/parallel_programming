# Задача 6. Функциональная декомпозиция с глобальной суммой

## Условие
Используя функциональную декомпозицию, перепишите задачу 5 для вычисления значения по формуле:
(sum_x + sum_y + sum_z) / 3N
где N — количество точек. Используйте глобальную сумму и критические секции.

## Файл
`task6.cpp`

## Сборка
g++ -fopenmp task6.cpp -o task6.exe

## Запуск
task6.exe <файл> [число_потоков]

Примеры:
task6.exe points.txt 1
task6.exe points.txt 4
task6.exe points.txt 8

## Описание
Программа читает координаты точек из файла и вычисляет выражение
(sum_x + sum_y + sum_z) / 3N.

Работа разделена на три независимые секции:
- Секция 1: считает сумму по X.
- Секция 2: считает сумму по Y.
- Секция 3: считает сумму по Z.

Каждая секция работает в своем потоке. Когда секция заканчивает
вычисления, она добавляет свой результат в ОБЩУЮ переменную global_sum.
Чтобы избежать состояния гонки (race condition) при одновременной записи
трех потоков в одну переменную, используется критическая секция 
(#pragma omp critical).

## Примечание
Результат должен совпадать с геометрическим центром из задачи 5.
Для тестового файла со средними значениями (49.5, 49.5, 49.5)
результат будет: (49.5 + 49.5 + 49.5) / 3 = 49.5.
