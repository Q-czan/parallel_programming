# Задача 5. Геометрический центр точек в 3D

## Условие
Написать программу, которая читает из файла координаты точек в 3D пространстве (x, y, z) и вычисляет геометрический центр (средние по x, y и z). Реализовать две версии: с распараллеливанием цикла и с функциональной декомпозицией.

## Файл
`task5.cpp`

## Сборка
g++ -fopenmp task5.cpp -o task5.exe

## Запуск
task5.exe <файл> [число_потоков]

Примеры:<br>
task5.exe points.txt 1<br>
task5.exe points.txt 8<br>

## Формат файла
Каждая строка — три числа через пробел:<br>
1.0 2.0 3.0<br>
4.0 5.0 6.0<br>
...<br>

## Описание версий
1. **Параллельный цикл** — `#pragma omp parallel for reduction(+:sum_x, sum_y, sum_z)`.
   Итерации цикла распределяются между потоками. Каждый поток суммирует свою часть точек.
   `reduction` безопасно собирает частичные суммы в общие переменные.

2. **Функциональная декомпозиция** — `#pragma omp parallel sections`.
   Каждая секция суммирует одну координату (x, y или z). Секции работают параллельно.
   В каждой секции суммирование выполняется последовательно, но три секции идут одновременно.
