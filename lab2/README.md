# Задача 4. Перемножение больших матриц

## Условие

Написать программу перемножения больших матриц. Сравнить время выполнения последовательной и параллельной программы на 2, 4, 8 потоках.

## Файл

`task4.cpp`

## Сборка

g++ -fopenmp task4.cpp -o task4.exe

## Запуск

task4.exe <размер_матрицы> <число_потоков>

## Примеры запуска

task4.exe 500 1
task4.exe 500 2
task4.exe 500 4
task4.exe 500 8

## Пояснение

Программа выполняет умножение двух квадратных матриц A и B размера n×n
тремя вложенными циклами:
    C[i][j] = sum(A[i][k] * B[k][j]) по k

Сначала выполняется последовательная версия, затем — параллельная
с указанным числом потоков. Распараллелен внешний цикл по i.
Для защиты от гонок данных ничего не нужно: каждая итерация по i
пишет в свою строку C[i][*], строки независимы.

Ускорение вычисляется как отношение времени последовательной версии к времени параллельной.
