# Задача 2. Сглаживание массива

## Условие

Объявлен массив из 16000 элементов, инициализированный так, что значение элемента равно его порядковому номеру: `a[i] = i`.

Создать результирующий массив `b`, в котором (за исключением крайних элементов) будут средние значения исходного массива:

b[i] = (a[i-1] + a[i] + a[i+1]) / 3.0

Запустить программу с 8 потоками при различных типах распределения работ.

## Файл

`task2.cpp`

## Сборка

g++ -fopenmp task2.cpp -o task2

## Запуск

OMP_SCHEDULE="<тип>[,<chunk>]" ./task2 <число_потоков> <размер_массива>

**Примеры:**

OMP_SCHEDULE="static"      ./task2 8 16000
OMP_SCHEDULE="dynamic"     ./task2 8 16000
OMP_SCHEDULE="guided"      ./task2 8 16000
OMP_SCHEDULE="static,1000" ./task2 8 16000
OMP_SCHEDULE="dynamic,100" ./task2 8 16000

## Пояснение

В программе используется `#pragma omp parallel for schedule(runtime)`. Тип распределения задаётся через переменную окружения `OMP_SCHEDULE`, что позволяет перебирать варианты без перекомпиляции.

| Тип | Поведение |
|-----|-----------|
| `static` | Итерации равномерно делятся между потоками (блоками по умолчанию). |
| `dynamic` | Поток забирает следующий блок итераций по завершении предыдущего. |
| `guided` | Размер блока динамически уменьшается по мере выполнения. |
| `static,1000` | Статическое распределение блоками по 1000 итераций. |
| `dynamic,100` | Динамическое распределение блоками по 100 итераций. |

## Ожидаемый вывод

Потоков: 8, n = 16000, время: 0.000123 с
b[1] = 1, b[15998] = 15998

При разных типах распределения время может незначительно отличаться. Для данной задачи (равномерная нагрузка на итерацию) разница минимальна, однако `dynamic` и `guided` дают лучшую балансировку при неравномерной нагрузке.
