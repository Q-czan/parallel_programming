# Задача 1. Вывод идентификаторов потоков

## Условие

Написать программу, в которой каждый поток печатает:
- свой идентификатор;
- общее количество потоков;
- строку `Hello World`.

Запустить программу с 8 потоками. Ответить на вопрос: всегда ли вывод идентичен? Почему?

## Файл

`task1.cpp`

## Сборка

g++ -fopenmp task1.cpp -o task1

## Запуск

./task1 <число_потоков>

**Примеры:**

./task1 1
./task1 2
./task1 4
./task1 8

## Ожидаемый вывод (пример для 4 потоков)

Поток 0 из 4: Hello World
Поток 2 из 4: Hello World
Поток 1 из 4: Hello World
Поток 3 из 4: Hello World

Порядок строк может отличаться при каждом запуске.

## Ответ на вопрос

Вывод **не идентичен** от запуска к запуску. Причина — отсутствие синхронизации между потоками: потоки выполняются параллельно, и планировщик операционной системы определяет, какой поток и когда получит доступ к `stdout`. В OpenMP по умолчанию порядок выполнения потоков не определён, поэтому строки могут выводиться в произвольном порядке. Это классический пример **состояния гонки** (race condition) на общем ресурсе — стандартном потоке вывода.
